# Security policy

## Supported versions

Only the latest minor release of `@pfm-solutions/ngx-theme` receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub private vulnerability reporting](https://github.com/PFM-Solutions/ngx-theme/security/advisories/new).

We acknowledge reports within 5 business days and keep you informed until a fix is released.
Once fixed, the vulnerability is disclosed in a GitHub security advisory, crediting you unless you prefer otherwise.
